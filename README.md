# Prueba de Certificación: Proyecto Final de Excel con IA

* **Estudiante:** Andres Santiago Dueñas Peña
* **Curso:** Herramientas de Excel y Análisis de Datos (Universidad EAN)

## Descripción del Proyecto
Este proyecto integrador (Prueba de Certificación) consiste en el desarrollo de un modelo automatizado en Excel para el control y gestión de presupuesto de gastos personales. Utiliza funciones avanzadas de suma condicional (`=SUMIF`) y un Dashboard interactivo para evaluar la ejecución real frente a lo estimado.

## Contenido del Repositorio
* `Proyecto EAN 1.xlsx`: Archivo principal de Excel que incluye las hojas de Presupuesto, Registro de Gastos, Dashboard con gráficos analíticos y Documentación.
* `Bitácora e Informe Técnico.docx`: Informe detallado que incluye la descripción del problema, el proceso analítico y la reflexión ética sobre el uso de la IA.

## Conclusiones principales
- Las categorías de Mercado y Servicios Públicos concentran el mayor porcentaje de egresos mensuales.
- La automatización mediante fórmulas de resumen facilita un seguimiento en tiempo real y una detección oportuna de desviaciones financieras.
- La validación humana es indispensable al usar herramientas de análisis automatizado para garantizar la integridad y la ética en el manejo de datos.
